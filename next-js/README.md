# MMD Viewer (Next.js) — 3D弾幕プロトタイプ

Three.js + MMD モデルの上で、東方風の弾幕(弾幕風)パターンを3D空間に展開して撃ち合うプロトタイプです。  
元は単なるMMDビューアーのHTML実装でしたが、段階的にNext.js化しつつ弾幕エンジンとしての機能を追加しています。

## 主な機能

- **ステージ / 敵の分離選択**: 背景となる建物モデル(紅魔館・白玉楼)と、弾幕を撃つ敵キャラクター(ちびレミリア)を別々に選んで同時表示できます。
- **弾幕コマンド**: `ring` / `fan` / `scatter` / `laserSweep` などの3D弾幕パターンをテキストコマンドで発射できます。詳細な引数・デフォルト値は [`/reference`](http://localhost:3000/reference) ページ(`app/reference/page.tsx`)にまとめてあります。
- **被弾・かすり判定**: 自機(現状はカメラ)と弾・レーザーの距離判定を実装。被弾でカウント、かすり(近接ニアミス)は1発につき1回だけカウントします。
- **発射位置の手ボーン追従**: 敵モデルのスケルトンから右手/左手のボーン(手先→手首→手→腕の順でフォールバック)のワールド座標を取得し、そこから弾を発射します。UIの「発射位置」トグルで左右を即時切り替え可能。敵アクター未登録時は座標(0, 200, 0)にフォールバックします。
- **レスポンシブレイアウト**: コントロール類を右サイドバー(幅380px)に集約し、canvasは`ResizeObserver`でウィンドウサイズに追従して最大限表示されます。

## 動作環境

- Next.js 16.2.4
- three ^0.152.2
- Node.js (LTS推奨)

## セットアップ

1. 依存インストール
   npm install

2. 開発サーバー起動
   npm run dev

3. ブラウザで確認
   http://localhost:3000
   （弾幕コマンドのリファレンスは http://localhost:3000/reference ）

## モデル配置ルール

- MMDファイルは public 配下に置く
- 例:
  - public/mmd/紅魔館/紅魔館.pmx
  - public/mmd/remilia/ちびレミリア/ちびレミリア.pmx
- コード側の参照は public を含めず、先頭スラッシュで指定する
  - /mmd/紅魔館/紅魔館.pmx
- ステージ・敵の一覧は `app/page.tsx` の `STAGES` / `ENEMIES` 配列に追加する

## 実装メモ

- 描画処理はクライアント側で実行する
- Three.js初期化は useEffect 内で行う
- canvas は querySelector ではなく ref で取得する
- アンマウント時に renderer と controls、ResizeObserverを破棄する
- 弾幕パターンの発射源座標は `SceneController.getOrigin()` に一本化されている（優先順位: 手のボーン → 敵モデルの座標 → 固定座標(0,200,0)）
- 敵モデルはMMD標準スケールのままだとこの世界の距離感(弾速600/秒、リング半径2000超)に対して小さすぎるため、10倍スケールで配置している

## よくあるエラー

### 404 Not Found (PMX)
原因:
- ファイルシステムパスをURLとして指定している

対処:
- modelUrl を /mmd/... 形式にする
- 実ファイルが public/mmd/... に存在するか確認する

### Module not found (MMDAnimationHelper)
原因:
- three のバージョン差異
- three.jsのバージョン関連でうまくいかないときは以下をお試しください
npm uninstall three
npm install three@0.152.2

対処:
- three のバージョンを 0.152.2 に固定する
